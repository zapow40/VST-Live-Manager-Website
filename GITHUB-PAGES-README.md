# VST Live Manager — GitHub Pages package

## GitHub Pages
Put `index.html`, `404.html`, `images/`, `scripts/`, and `styles/` in the repository root.
Then go to **Settings → Pages → Deploy from a branch → main → / (root)**.

For a project repository, open:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

The original export referenced `/downloads/vst-live-manager-v2.7.lua`, but that Lua file was not present in the uploaded ZIP. Add the real file at:
